# Generated API client

`core-domain.ts` and `event-ingestion.ts` are generated by `npm run generate:api`
(openapi-typescript) from the OpenAPI specs in `motifpath-specs`. **Do not edit by hand.**

Regenerate after any spec change in `motifpath-specs`, and commit the result as a
separate `chore(codegen)` commit. The generator expects `motifpath-specs` as a
sibling checkout; override the location with the `SPECS_DIR` environment variable.

Consume these through `src/api/` (the `coreApi` / `eventApi` clients) and the
`useApi()` composable — never import generated files directly into a component.
